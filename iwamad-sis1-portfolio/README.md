About the Site
This is my personal portfolio website built using pure HTML, CSS, and JScript. The page presents my background as a KBTU student, features my Week 1 to Week 4 web development builds, and includes a functional contact form. The site is fully responsive and supports light and dark themes

Design Decisions
1 Responsive Layout: On mobile screens, project cards are stacked in a column, while on larger screens they automatically arrange into a row using Flexbox
2 Color Palette**: Simple contrasting colors and a dark mode class are used to ensure comfortable viewing at any time of day
3 Custom Validation: The contact form is built without external libraries and checks field completion and email format correctness with clear error messages
